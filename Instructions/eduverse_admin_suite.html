Simulation Tips

  • 🛡️ Multi-Role Login: Log in using any of the 12 administrative roles (Super Admin gets complete server diagnostics; Librarian manages catalog; Security checks QR codes).
  • 🎨 Live Customizer: Go to Super Admin/Settings -> App Customizer, use Hue Sliders to change brand colors, edit the school name, and see the mockup update dynamically!
  • 🚪 Disable Modules: Toggle LMS, Transport, or Library features. They will instantly disappear or lock in dashboard navigation grids.
  • 🚌 GPS Simulation: Go to Transport. The vector map shows animated real-time bus movements. Click "AI Optimize" to run conflict-checks.
